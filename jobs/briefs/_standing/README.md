# Standing files for every brief

Copy these into every new brief, whatever its kind.

- `rules_dials.md` and `dials_template.csv`: the dial evidence every seating brief must collect, for every dial we score. A brief that seats a brand is not complete without them. Seating briefs add the section "Dials" to their `BRIEF.md` and name `dials.csv` as a return file.
