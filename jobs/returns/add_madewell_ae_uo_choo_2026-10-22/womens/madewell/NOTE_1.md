## Method and limits

- Census: ten women's clothing category pages, paged by offset, de-duplicated on the style code: 231 styles. Sample: 79 (stratified in proportion to category size), all stating a composition.
- Style URLs are the short form `madewell.com/p/<code>/`, which resolves to the product page.
- Cashmere 2.5%, silk 1.3%, linen none, wool 15.2% (six SoftWool merino styles), cotton 70.9%, polyester-led 3.8%. Elastane in the main fabric on 26 of 79; elastomultiester (EME) on some denim not counted as elastane.
- Madewell product pages never name a country, only "Imported." (79 of 79). Cone and Orta denim are named on 2 of 25 sampled jeans pages.
- Facts: B Corp directory search "madewell" returned three unrelated companies. GOTS free-text search returned no records. The RealReal page loaded after a short interstitial (no check box). Vinted's catalogue API returned 403 when called directly, so I did not use it; the brand id 55015 came from the site's own Brand filter.
