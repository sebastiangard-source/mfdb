## The tie question is mapped — it is one edit, and it barely matters

You have no tie-break rule, and largest remainder needs one: when two categories have the same
fractional remainder and one point is left, the winner is decided by iteration order. The file
currently resolves that tie both ways.

**Seven ties move a published cell**: Peserico, Jack Victor, Duck Head, Stone Island, Sid Mashburn,
Gucci, Amiri. Twenty-four more are inert.

**Six of the seven already agree with the obvious rule.** Only **Peserico** disagrees with *both*
conventions — its second point is an exact 3/7 tie between natural and cellulosic, awarded to
cellulosic, though natural is simultaneously the earlier column and the far larger raw count
(192 against 3).

Recommended: **at an exact tie the point goes to the earlier column** — natural, then synthetic, then
cellulosic, then no-composition. That is **one edit in the whole file**: Peserico `natural_pct` 91→92,
`cellulosic_pct` 2→1. The inverse rule would confirm Peserico and change the other six. "Larger raw
count wins" goes silent at Duck Head and Jack Victor, where the tied categories hold identical counts.

I have not applied it. It is a ruling, not a fix, and the file is consistent either way — the honest
headline is that it barely matters, which is itself the useful finding.

Also worth knowing: the file is **more checkable than the last audit claimed.** That round put the
not-re-derivable share at 87 rows, "roughly 45%", and called its own list conservative. Matching every
count quadruple across every working paper closes 51 of those 87 and finds 11 it missed — so the real
figure is **47 of 192, about 24%.** That is load-bearing, because Sid Mashburn's genuine tie sits on a
row the previous audit had written off as unverifiable.

And one structural point about ties that is worth putting in the spec: with four categories of which
three are published, **a tie that straddles the allocation cutoff always moves a published cell.** The
inert group can only ever contain ties that do not straddle it. There is also nothing in the file
within 0.005 *at the cutoff*, but **34 rows would develop a fresh exact tie if a single style moved
between categories** — which, given the catalogue churn this pass has been living with, is the more
useful sensitivity measure than remainder gaps.
